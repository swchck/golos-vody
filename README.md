# Голос воды

Веб-версия колеса выбора историй из игры _Where the Water Tastes Like Wine_.
16 карт Таро по кольцу, разделённому пополам; стрелка-указатель из центра наводится
на карту, клик раскрывает истории этой карты выбранного настроения — с иконкой и
пересказами, как в игре.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

Сборка статики: `npm run build` → каталог `dist/`.

## Как устроено

- **Три режима** (сверху): **Колесо** — как в игре; **Все истории** — каталог всех 218;
  **Костёр** — помощник: выбираешь персонажа и что он просит, приложение показывает, какие
  собранные истории ему ещё не рассказаны (подходящие по настроению — вперёд и подсвечены),
  «Рассказал» отмечает историю и занимает карту на раунд (карта — раз за 5 историй).
- **Подсказка** (в шапке) — шпаргалка «фраза персонажа → категория» для мутной локализации.
- **Статистика** (клик по «собрано N/218») — % сбора, полные (грейд III), по настроениям и картам.
- **Умные фильтры** в каталоге: не полные / не рассказаны + сортировка по грейду/адресатам/алфавиту.
- **Настроение** — 5 типов из таблицы: страшные, приключения, весёлые, грустные, светлые.
  В колесе карты без историй выбранного типа гаснут.
- **Колесо** — 16 карт Таро. Стрелка-указатель **идёт за курсором** без клика; **клик**
  открывает истории карты в центральном «столе». Клавиши `← →` — целиться, `Enter` — открыть.
- **Эволюция (грейды).** У каждой истории 3 грейда, как в игре: значок **глаза**
  (закрытый → приоткрытый → полностью открытый). Клик по глазу поднимает грейд; при раскрытии
  истории видны все грейды-пересказы, а услышанные помечены открытым глазом.
- **Кому рассказано.** У каждой истории — сетка из 17 адресатов (16 персонажей + **Волк**)
  с портретами; отмечай, кому уже рассказал (персонаж не слушает историю дважды). На строке —
  счётчик рассказов.
- **Коллекция.** Грейды и отметки «рассказано» хранятся в браузере (localStorage). Кнопки
  **Экспорт/Импорт** выгружают и загружают весь прогресс в JSON.
- **Все истории** — каталог всех 218 (по умолчанию — все настроения), фильтр «в котомке /
  не собраны», поиск.
- **Модалка истории** — клик по истории открывает крупное окно поверх: карта, все 3 грейда,
  «где искать», «кому рассказано». Esc/клик по фону — закрыть.
- **Тема день/ночь** — переключатель в шапке, выбор запоминается.
- **Поиск** — по словам в тексте историй.

> В исходном Google-листе ровно **218** сюжетных историй (каждая с 3 грейдами) + 16 историй
> персонажей отдельно. Автор гайда отмечает, что таблица может быть неполной на 1–2 истории —
> если найдётся недостающая, её легко дописать в `src/data.json`.

## Данные и ассеты

- `src/data.json` — 16 карт × 5 настроений, 218 историй с грейдами, из исходной таблицы.
- `public/icons/*.png` — ксилографические карты Таро с фанатской вики игры.

## Что осталось за кадром (ограничения источников)

- **Отдельных картинок у историй нет** ни на вики, ни в гайде — в игре «иконка истории»
  это как раз глаз грейда (реализовано). Уникальные рисунки лежат только в файлах игры.
- **Точных мест на карте у большинства историй нет** by design: они случайны и собираются
  в фиксированном порядке. В «где искать» дан честный ориентир, а не ложная точка.

## Публикация на GitHub Pages

Всё для деплоя уже готово: GitHub Action, PWA-манифест, service worker, иконки,
OG-превью для шеринга и SEO-разметка.

Адрес Pages: **https://swchck.github.io/golos-vody/** (уже прописан в `index.html`,
`public/robots.txt`, `public/sitemap.xml`). При форке замени `swchck.github.io/golos-vody`
в этих трёх файлах на свой адрес.

1. Запушь проект в репозиторий `golos-vody` (ветка `master`).
2. **Settings → Pages → Build and deployment → Source: GitHub Actions** (включается один раз).
3. Пуш в `master` — Action соберёт и опубликует. Готовый адрес будет в разделе Pages.

Локальная проверка боевой сборки: `npm run build && npm run preview`.

Пути к ассетам относительные (`base: './'` в `vite.config.js`), поэтому работает и на
`user.github.io/<repo>/`, и на своём домене.

### Что уже настроено

- **PWA** — `manifest.webmanifest` + `sw.js` (офлайн, установка на телефон/десктоп).
- **Иконки** — `favicon.svg`, `icon-192/512`, `apple-touch-icon` (оригинальный солнце-глаз).
- **OG-превью** — `og.png` (1200×630): кремовый альманах с самим Колесом из 16 карт и
  стрелкой-указателем. Генерится из `tools/og.html` командой `node tools/render-og.mjs`
  (playwright + sharp). Использует иконки карт из `public/icons` (арт игры).
- **SEO** — title/description/keywords, canonical, Open Graph + Twitter Card,
  `theme-color` (день/ночь), `robots.txt`, `sitemap.xml`, JSON-LD (`WebApplication`).
- **Шеринг** — при отправке ссылки в соцсети/мессенджеры показывается карточка `og.png`.
